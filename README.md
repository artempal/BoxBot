# BoxBot - Telegram бот для учета и хранения вещей

**ВНИМАНИЕ! Код написан с помощью генеративного ИИ и может иметь множество багов.**

BoxBot - это Telegram бот, который помогает пользователям отслеживать вещи и места их хранения. Бот разработан с использованием бессерверных технологий AWS Lambda и AWS DynamoDB.

## Основные функции

- Управление местами хранения
- Учет вещей в местах хранения
- Поиск вещей по названию
- Перемещение вещей между местами хранения
- Статистика поиска вещей
- Поддержка фотографий для вещей и мест хранения

## Команды бота

- `/storage` - Управление местами хранения
- `/item` - Просмотр списка вещей
- `/stat` - Статистика поиска
- `/help` - Справка и помощь

## Технический стек

- Python 3.9+
- python-telegram-bot
- AWS Lambda
- AWS DynamoDB
- AWS API Gateway
- Docker (для локальной разработки)

## Настройка окружения разработки

### Предварительные требования

- Python 3.9+
- Docker
- AWS CLI (для деплоя)

### Установка и запуск

1. Клонировать репозиторий:
   ```
   git clone https://github.com/artempal/BoxBot.git
   cd BoxBot
   ```

2. Создать виртуальное окружение:
   ```
   python -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

3. Установить зависимости:
   ```
   make setup
   ```

4. Создать файл `.env` на основе `boxbot/env_example` и заполнить его:
   ```
   cp boxbot/env_example .env
   ```

5. Запустить локальную DynamoDB:
   ```
   make setup-local
   ```

6. Запустить бота в режиме разработки:
   ```
   make run
   ```

## Настройка для продакшена

### Деплой на AWS Lambda

1. Настроить AWS CLI:
   ```
   aws configure
   ```

2. Создать Lambda функцию, таблицу DynamoDB и настроить API Gateway с помощью AWS Management Console или AWS CDK/CloudFormation.

3. Обновить `.env` файл с продакшен-настройками.

4. Собрать и загрузить пакет в Lambda:
   ```
   make deploy
   ```

5. Настроить вебхук:
   ```
   make setup-webhook
   ```

## Ограничения

- Максимальное количество мест хранения на пользователя: 100 (настраивается)
- Максимальное количество вещей на пользователя: 1000 (настраивается)
- Фотографии хранятся в Telegram, в базе сохраняется только file_id

## Безопасность

- Доступ к боту ограничен списком разрешенных Telegram ID
- Данные разделены по ID пользователей
- Нельзя удалить место хранения, содержащее вещи
